# 资料与统计口径

## 当前可验证范围

模型选择、论文结构和写作建议来自只读子模块 `Lupynow/math-modeling-skills`。该知识仓库由维护者长期整理公开数学建模资料、获奖论文样本和实践经验；其中部分历史汇总数字尚未提供可独立复算的逐篇来源清单。

因此，当前版本执行以下规则：

- 不再把这些数字作为可外推的普遍规律。
- 没有来源清单支持时，使用“在维护者整理的样本中较常见”等审慎表述。
- 比赛规则、页数和 AI 使用报告要求以当届官方文件为准。
- 引用论文观点时记录作者、标题、年份、链接/DOI 和支持的具体判断。
- 不把未核验的搜索摘要当作论文证据。

## 后续资料清单格式

为尊重版权，仓库不收录完整获奖论文。后续只维护元数据：

| 字段 | 说明 |
|---|---|
| `competition` | CUMCM、MCM/ICM 等 |
| `year` | 比赛年份 |
| `problem` | 题号 |
| `award` | 奖项层级 |
| `title` | 论文标题 |
| `public_url` | 合法公开来源 |
| `features` | 是否包含流程图、灵敏度分析、AI 报告等 |
| `verified_at` | 最后核验日期 |

只有在元数据清单可以公开、去重并复算后，README 才重新展示精确样本数量和比例。

## 评测口径

AI Agent 的 24 条样例均为合成短题，不复制完整官方赛题。评测结果只用于：

- 检查分类回归。
- 检查输出 Schema。
- 检查引用路径。
- 比较 Prompt 或模型版本。

它不能证明真实竞赛成绩，也不能替代人工判断模型是否适合具体赛题。
